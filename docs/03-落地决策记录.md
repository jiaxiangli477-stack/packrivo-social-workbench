## Q4 审核闸门：敏感项强制人工，其余 AI 达标即发

已实现，落在 `app/server.mjs` 的 `sensitiveHits()` + AI 预审接口：

| 类别 | 触发示例 | 行为 |
|---|---|---|
| price 价格/折扣 | `$0.89`、`20% off`、`报价` | 即使 AI 通过也强制 `pending_review` |
| promise 承诺/保证 | `guarantee`、`100%`、`free shipping`、`包退` | 同上 |
| cert 认证/环保声明 | `FSC`、`ISO 9001`、`biodegradable`、`可降解认证` | 同上 |
| case 客户案例 | `case study`、`our client` | 同上 |
| contact 联系方式 | `WhatsApp`、`@xx.com`、`+1 415…` | 同上 |

- 当前 `publish_mode=auto`：**没有命中敏感项**的内容 AI 通过即放行；命中的强制转人工。
- 开关与自定义词在设置页：`review_sensitive_enabled`（1/0）、`review_sensitive_extra`（逗号分隔）。
- 实测：一条含 `$0.89 / 20% off / FSC / WhatsApp` 的内容，AI 打 92 分通过，被闸门拦下转人工（`forced_manual=true`，状态 `pending_review`）。

## Q9 视频：AI 脚本 + 素材先跑，接口先留好

- 一期：TikTok 版本本身就是**带分镜的口播脚本**（0–3s 钩子 / 画面 / 字幕 / 时长），可直接照着剪；素材用 Pexels + AI 生图 + 你后续上传。
- 二期接口已预留，你放好 API 后不用改代码，直接调：

```http
POST /api/video/generate
Content-Type: application/json

{"prompt":"30s TikTok: kraft mailer box one-sheet assembly, close-up fold, CMYK print detail",
 "content_id": 6,
 "options": {"duration": 15, "aspect_ratio": "9:16"}}
```

```json
// 成功
{"ok": true, "url": "https://cdn.example.com/xxx.mp4", "via": "可灵"}
// 未配置
{"ok": false, "state": "pending_config", "reason": "未配置视频接口（模型接入页添加一个用途=视频的接口）"}
```

接入方式：模型接入页 → 添加接口 → 用途选「视频」→ 填 Base URL / 模型名 / API Key / 优先级。调用路径默认 `/videos/generations`，可在设置 `video_api_path` 改（各家不一样，比如 `/v1/video/generations`）。多个视频接口按优先级主备降级，返回的 URL 自动登记进素材库（`asset` 表）。

**给智能体调用**：这个端点是本机 HTTP 接口，任何能跑命令的智能体都能用：

```bash
curl -s -X POST http://127.0.0.1:8795/api/video/generate \
  -H "content-type: application/json" \
  -d '{"prompt":"...","content_id":6}'
```
