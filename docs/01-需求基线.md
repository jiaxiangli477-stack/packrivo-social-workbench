## 3. 技术方案基线（✅ 已锁定）

四模块实现（原文功能模块清单表）：

| 模块 | 做什么 | 用什么实现 |
|---|---|---|
| 爆款库 | 按关键词搜各平台爆款，按互动数据排序，选一条进入二创 | Apify 采集 TikTok + TikTok Creative Center / Meta 广告库 |
| AI 内容流水线 | 拆解爆款结构 → 套用到产品 → 生成多平台、多语言文案和配图 | Claude（主脑）+ GPT / DeepSeek API 分工 |
| 发布中心 | 一处管理所有账号，排期发布到 FB、IG、TikTok 等 | Postiz（开源，自带 MCP 接口） |
| 数据看板 | 各平台表现 + 独立站引流效果 | 自建看板，接 Postiz 数据和 GA4 |

**总方案锁定：Postiz（发布）+ Apify（采集）+ GA4（引流数据）+ 模型中转站（模型接入与切换）。** 部署在用户自己的 netcup 服务器上（Docker 安装见准备清单）。

## 4. MVP 功能范围基线（✅ 已锁定，按原文 MVP/二期切分）

**MVP（一期）范围：**

- 爆款库：关键词搜 TikTok 爆款，按播放量/互动率排序，卡片展示；手动粘贴任意平台帖子链接加入爆款库
- AI 二创：选中爆款 → 拆解结构（开头钩子、痛点、产品露出、结尾引导）；套用到自己产品，一稿生成 FB / IG / TikTok 三个版本 + 多语言；与原帖相似度检查，太像自动重写
- AI 二创（视频）：TikTok 短视频脚本 + 分镜（MVP）；**AI 生成视频 = 二期，MVP 不做**
- 素材：产品资料库（产品图、卖点、目标客户，写一次反复用）；AI 生图（基于产品图换场景）+ Pexels 免版权图库
- 发布：Postiz 多平台排期、按目标市场时区定时；每条帖子自动加 UTM 链接回独立站；人工审核队列（通过/修改/打回）
- 数据：数据看板（见第 6 节）

**二期范围（不在 MVP）：**

- 竞品账号定时跟踪、FB/IG 自动采集
- 每周自动复盘报告、推荐下周选题
- 评论、私信 AI 辅助回复
- 多用户、权限、审批流
- AI 生成视频

> 对短视频的影响：用户要「图文 + 短视频都要、支持 AI 生成素材」，但 AI 生成视频按原文是二期——**MVP 阶段短视频素材以收集上传为主，AI 生成视频不提供**。是否提前，见 02 文件提问。

## 5. 模型接入页要求基线（✅ 已锁定）

- 工作台内置「模型接入」设置页：**文字、图片、视频模型都在此页配置，不用改代码**。
- 页面 7 项要求（原文表）：

| 功能 | 要求 |
|---|---|
| 自定义接口 | 填写名称、Base URL、API Key、模型名；支持 OpenAI 兼容格式的中转站和官方接口 |
| 用途分类 | 每个接口标明用于文字 / 图片 / 视频 |
| 测试连接 | 一键测试接口是否可用，并拉取可用模型列表 |
| 优先级与备用 | 每类任务按顺序尝试：主接口失败自动切到备用接口 |
| 按任务指定模型 | 如初筛用 DeepSeek、英文文案用 GPT、视频用中转站的可灵 |
| 用量统计 | 按接口和任务统计调用次数与花费，在数据看板展示 |
| Key 安全 | Key 加密保存，页面上只显示后 4 位 |

- **派工通道（已锁定）**：

| 工具 | 默认通道 | 备用通道 |
|---|---|---|
| Codex CLI（GPT） | ChatGPT 账号登录 | 中转站（Codex 配置里加自定义提供商，切换即用） |
| Gemini CLI | Google 账号免费额度 | 中转站或 Gemini API Key |
| PAL（调用其他模型） | 通过 clink 调用上面两个 CLI | 中转站自定义接口、OpenRouter |
| 社媒工作台（服务器） | 模型接入设置里的主接口 | 同一页配置的备用接口 |

- 开发阶段派工优先用免费 CLI（Codex、Gemini），不可用时改走中转站；CLI 本身支持自定义接口地址，额度用完/账号不可用时可切换到中转站继续用 GPT 等模型，派工流程不变。
- **本机中转站地址和 Key 统一填在 `C:\Users\21996\.ai-keys\keys.env`，Codex 和 PAL 共用。**

## 6. 数据看板基线（✅ 已锁定）

看板回答一个问题：**哪个平台、哪类内容给独立站带来了最多访问和订单。**

核心指标定义：

| 指标 | 公式 |
|---|---|
| 互动率 | （点赞 + 评论 + 分享 + 收藏）÷ 曝光 |
| 引流访问 | GA4 中 utm_source 为该平台的会话数 |
| 内容 ROI | 引流订单金额 ÷ 当周 API 和采集费用 |

四个页面：

| 页面 | 展示内容 | 数据来源 |
|---|---|---|
| 总览 | 本周发帖数、总曝光、总互动、独立站引流访问和订单，对比上周 | Postiz + GA4 |
| 平台对比 | 各平台的曝光、互动率、点击、引流访问、转化，按周趋势 | Postiz + GA4（按 UTM 来源拆分） |
| 帖子排行 | 每条帖子的数据排行，标注它模仿的爆款和使用的内容结构 | Postiz + 工作台数据库 |
| 爆款库 | 按关键词看爆款数量、平均播放、热门话题标签 | Apify 采集结果 |
