# 04 · 关键词找爆款（帖子 / 文章 / 视频）

需求：用关键词自动找爆款内容，选中后进爆款库，再一键带到 AI 二创。

## 现在能跑的来源（都已实测）

| 来源 | 类型 | 数据 | 状态 |
|---|---|---|---|
| YouTube 搜索 | 视频 | **真实播放量**、频道、发布时间、字幕摘要 | ✅ 已跑通，无需 Key |
| Google News RSS | 文章 | 真实标题、媒体名、发布时间（无互动数据） | ✅ 已跑通，无需 Key |
| Bing News RSS | 文章 | 备用新闻源 | ✅ 已跑通，无需 Key |
| Apify | TikTok / IG / FB 视频 | 真实播放/点赞/评论 | ⚠️ 待配置：设置页填 Apify Token + Actor ID |
| 手工粘贴 | 任意 | 你贴什么就是什么 | ✅ 已跑通 |

**已排除的路子**（试过，不通，不再浪费时间）：

- Reddit JSON API：`www.reddit.com/search.json` 与 `api.reddit.com` 都返回 403（被反爬），RSS 也返回 HTML 壳。
- DuckDuckGo HTML：偶发 202（限流），结果不稳定。
- Bing 网页搜索：返回结果与关键词严重不相关（出现"California Custom Trailers"之类），弃用；Bing **新闻** RSS 可用。

## 打分口径（页面上能区分）

- **视频（measured）**：`score = 20 + 12 × log10(播放量)`，上限 100。1 万播放 ≈ 68，10 万 ≈ 80，100 万 ≈ 92。
- **文章（estimated）**：`45 + 相关性 15（标题含关键词）+ 时效 20（7 天内）/10（30 天内）`。**没有互动数据，分数是估算**，页面上标「估」。
- 入库时保留 `score_type`（measured / estimated / manual），后续排序和报表都能区分，不混着当真实热度看。

## 用法

1. 「爆款库」→ 勾选关键词（默认给了 20 个包装类英文词），或自己补（英文逗号分隔，最多 10 个）
2. 选来源（YouTube / Google News / Bing News），设每个词取几条、最低分
3. 搜索 → 结果按分数排序，可勾选 → 入库选中
4. 入库后可以「拆解」出结构（hook / 痛点 / 证明 / CTA / 分段骨架）
5. 「去二创」直接跳到生成页，自动带上这条参考、并勾上对应平台

## 接口

```http
GET  /api/discover/sources                    # 来源清单与配置状态
POST /api/discover                            # {keywords:[], sources:[], per:5, min_score:0}
POST /api/hotspots/bulk                       # {items:[...]} 批量入库
POST /api/hotspots/{id}/deconstruct           # 拆结构（会带上视频字幕摘要）
```

`/api/discover` 返回：`{ok, count, items[], errors[]}`，`items` 里每条含 `kind(source=video/article) / title / url / author / published / days / stats{views|outlet} / score / score_type / keyword`。

## 接 Apify 之后能多拿到什么

设置页填 `apify_token` + `apify_actor`（例如 TikTok 的 `clockworks/tiktok-scraper`），`/api/discover` 里 sources 加 `"apify"` 即可。返回会带 `views / likes / comments`，分数按 measured 计算，能覆盖 TikTok、Instagram、Facebook 的真实互动——这是目前唯一能拿到社媒真实数据的通道。

## 已知边界

- 文章源没有互动数据，只能按「新闻价值 + 时效」排序，不等于「爆款」；用它做选题参考，不要当热度指标。
- YouTube 搜索拿到的是搜索排序结果里的视频，不是全站热榜；已按播放量打分排序，但"新发布但播放低"的好素材可能排在后面。
- 平台风控：这些请求都是公开页面，频率低（一次搜索十条以内），没有登录态，不触发风控。
